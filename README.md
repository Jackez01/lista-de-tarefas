# API de Gerenciamento de Tarefas

API REST desenvolvida com FastAPI para gerenciamento de tarefas, utilizando PostgreSQL como banco de dados e SQLAlchemy como ORM.

## Funcionalidades

- Criar tarefas
- Listar todas as tarefas
- Atualizar tarefas existentes
- Remover tarefas
- Documentação automática com Swagger

## Tecnologias Utilizadas

- Python 3.12
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- Uvicorn
